Types of queries

- 1 x - push_front(x)
- 2 x - push_back(x)
- 3 - pop_front()
- 4 - pop_back()
- 5 i - output i-th element
---

**random**

just all 5 operations in random order

---

**random_default**

4 default operations in random order

---

**static**

container has size 500'000 and receives only 5-th queries
